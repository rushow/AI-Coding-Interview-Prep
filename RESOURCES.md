# Resources

Books and handouts for coding interview prep. Only freely licensed material is stored in this repo ([`books/`](books/)); everything else is linked to its official source.

## In this repo

| Book | Author | Best for |
| --- | --- | --- |
| [Competitive Programmer's Handbook](books/competitive-programmers-handbook.pdf) | Antti Laaksonen | Core algorithms and data structures, concise with C++ code (CC BY-NC-SA 4.0) |

## Interview-focused

| Book | Author | Best for | Where to get it |
| --- | --- | --- | --- |
| Cracking the Coding Interview (6th ed.) | Gayle Laakmann McDowell | 189 interview questions with solutions; the interview process end to end | [crackingthecodinginterview.com](https://www.crackingthecodinginterview.com/) |
| Programming Interviews Exposed | John Mongan, Noah Kindler, Eric Giguère | Walkthroughs of how to reason through classic problems out loud | Wiley (print and ebook) |
| Dynamic Programming for Interviews | Sam Gavis-Hughson | The FAST method for DP questions | Free from the author: [byte-by-byte.com/dpbook](http://www.byte-by-byte.com/dpbook) (the author asks that it be shared only through this link) |
| Data Structures and Algorithms Made Easy | Narasimha Karumanchi | Large bank of DSA problems by topic | CareerMonk Publications (print and ebook) |

## Algorithms in depth

| Book | Author | Best for | Where to get it |
| --- | --- | --- | --- |
| Introduction to Algorithms (3rd ed., "CLRS") | Cormen, Leiserson, Rivest, Stein | The reference text: proofs, analysis, every classic algorithm | [MIT Press](https://mitpress.mit.edu/) |
| Guide to Competitive Programming | Antti Laaksonen | Expanded, edited version of the Handbook above | [Springer](https://www.springer.com/978-3-319-72546-8) |
