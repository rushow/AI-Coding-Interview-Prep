## Competitive Programmer's Handbook — Antti Laaksonen

[`competitive-programmers-handbook.pdf`](competitive-programmers-handbook.pdf) (draft of July 3, 2018)

Covers time complexity, sorting, data structures, dynamic programming, graph algorithms, trees, range queries, string algorithms, geometry and more, with C++ examples.
